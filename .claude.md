# Project notes: Apex (Bittensor Subnet 1) miner

- SN1 = Apex (Macrocosmos): competition-based. Miners submit solution files through the `apex` CLI and don't run a live server. The leaderboard is winner-takes-all.
- The official repo is cloned into `./apex` (gitignored) by `scripts/setup_apex.sh`. Competition specs are in `apex/shared/competition/src/competition/<name>/README.md`, and they change. Re-read them before you change a solution.
- The `apex` CLI and `btcli` need WSL 2 or Linux. Solution development and `tools/local_eval.py` work on native Windows (Python 3.12).
- Current focus: `solutions/text_clustering/solution.py`
  - It must stay under 50,000 chars and may only import stdlib, numpy, sklearn, fastapi, uvicorn, and pydantic (versions pinned in requirements.txt).
  - Limits: CPU only, no internet, 1.5 GB RAM, 90 s per request.
  - Before suggesting a submission, run `python tools/local_eval.py solutions/text_clustering/solution.py`. Submissions cost TAO.
- Never read, print, or commit wallet files, mnemonics, or `.apex.config.json`.
